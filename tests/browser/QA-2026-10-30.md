# QA real de navegador — Surface_Recon (2026-10-30)

**Estado:** validación de alcance limitado, NO aprobación de lanzamiento ni conformidad WCAG completa. entorno de pruebas Windows; Microsoft Edge (Chromium) headless con DevTools Protocol. Servidor de la interfaz y sitio objetivo vinculados solo a `127.0.0.1`, sin tráfico externo.

## Escenarios comprobados

- Instancia actualizada de interfaz: perfil `unlimited` visible y seleccionado; autorización explícita requerida; errores de objetivo vacío y autorización faltante devuelven foco al control pertinente.
- Reconocimiento desde la interfaz contra `http://127.0.0.1:18043/`, fixture con enlaces a `/proyectos/` y `/contacto/`: se observan los recursos en el JSON exportado. La evaluación global muestra **Parcial** porque otras subcapacidades permanecen sin evaluar; no se presenta como ausencia de vulnerabilidades.
- Exportaciones REALES en el disco, abiertas y verificadas: HTML 9.892 bytes, JSON 17.184 bytes, CSV 2.448 bytes en primera ejecución; mismo `run_id` por ejecución. El HTML se reabrió con protocolo `file:` en Edge (tres tablas), el JSON se parseó y el CSV se abrió con `csv.DictReader` (16 registros, ocho columnas consistentes, valores del target presentes). Segunda ejecución `unlimited+low`: HTML 9.894, JSON 17.188, CSV 2.448 bytes; también PASS.
- Accesibilidad básica en navegador: documento `lang=es`, título H1 único, nombres accesibles de campos y casilla de autorización, jerarquía H1-H2, mensajes `role=status aria-live=polite`, navegación Tab (`target -> run`) con anillo de foco observado por entrada de teclado, respeto a `prefers-reduced-motion:reduce`. A 320, 390, 756 y 1365 px no hubo desbordamiento horizontal del documento; los tres botones de exportación siguen disponibles con altura de 48 px después de la evaluación a 390 px. Se capturaron pantallas.
- Contrastes indicativos en muestras de paleta: marca 11.63:1, texto secundario sobre panel 9.60:1, ayuda sobre panel 8.95:1, texto botón primario 9.84:1, pie 7.90:1. Cálculo manual sobre colores de diseño; no constituye una auditoría automatizada completa de contraste en fondos degradados.

## Hallazgos y acciones

1. El servidor de QA de un ensayo anterior (`18042`) quedó activo con código viejo: no mostraba `unlimited`. Se descartó esa sesión y se inició una instancia actualizada en `18044` y posteriormente `18045`; **no era un fallo de la versión candidata**.
2. Se detectó un defecto real: `ReconControls(profile='unlimited', noise='low')` devolvía límite de 60 solicitudes por prioridad del condicional. Corregido: `unlimited` conserva **cantidad de solicitudes sin tope**, el límite de tiempo de 3.600 s y el ritmo bajo/ausencia de proveedores externos. Nueva prueba unitaria.
3. Pruebas automáticas de Python (después de corrección): **141/141 PASS en Windows (35.64 s)**. Scripts Node mediante CDP: **PASS** con perfiles `unlimited/normal` y `unlimited/low`. `node --check` en ambos scripts PASS.
4. Las pruebas no certifican uso con lector de pantalla físico, compatibilidad de todos los navegadores/OS, descargas en otros gestores, conformidad WCAG integral ni capacidad de manejar sitios ilimitados sin congestión. Las pruebas del laboratorio no autorizan un merge PUBLIC.

## Reproducción de pruebas

Los scripts de tests/browser permiten ejecutar escenarios de navegador y exportación en un entorno de prueba local controlado. Los resultados históricos corresponden a versiones ensayadas y no sustituyen la validación del candidato final.

**Limitación:** esta evidencia no constituye aprobación de lanzamiento ni certificación completa de accesibilidad.
