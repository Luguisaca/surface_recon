# Security Policy

[Versión en español](SECURITY.md)

Surface_Recon is intended only for security assessments of assets you own or are explicitly authorized to test. Reconnaissance findings do not establish that a target is free of vulnerabilities.

## Reporting a vulnerability

Report vulnerabilities confidentially using **Security → Advisories → Report a vulnerability** in the official repository:

https://github.com/Luguisaca/surface_recon/security/advisories/new

Do not post sensitive details, proof-of-concept exploits, credentials or internal paths in public Issues, Pull Requests, Discussions or GitHub Actions logs.

## Scope and coordinated handling

In scope are reproducible weaknesses in distributed source code, dependencies, packaging, authorization controls and the local interface. Provide the affected version, reproduction conditions, impact and minimal steps without sharing third-party data or secrets.

Reports will be assessed and fixes/disclosure coordinated responsibly. No response-time commitment or reward is implied.

This channel does not authorize testing third-party systems.
