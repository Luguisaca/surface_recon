# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities through public issues.

Use GitHub's private vulnerability reporting for this repository when available. Include the affected version or commit, reproduction steps, observed impact, and any relevant evidence that can be shared safely.

Do not include secrets, credentials, personal data, or data from systems you are not authorized to assess.

## Scope

Security reports about Surface_Recon itself are welcome. Authorization to use this software does not grant authorization to test third-party systems.
